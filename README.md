# Welcome to PalettePal
PalettePal is an application that allows you to upload an image, select a color and a artistic preset, and six-color palette of complentary colors will be generated for you.
This application is a tool to be used alongside your other art applications and the goal of this application is to help artists find the proper complentary colors to use for your artpieces. 
Artists need additional colors to add depth for their pieces, and finding these can be quite time consuming, so we used color math to help create a palette to handle this task.
### The colors that will be generated will be:
- 1 Lineart
- 2 Shadows
- 2 Highlights
- 1 Accent

## How to run PalettePal

You may need to install a few libraries if you dont have them on your system 

### Python
Navigate to https://www.python.org/downloads/ and follow the instruction to download python

### Pyside6
to download Pyside6: run _pip install pyside6_ in your terminal

### Colour-Science
to download Pyside6: run _pip install colour-science_ in your terminal

### Pillow
to download Pyside6: run _pip install pillow_ in your terminal

## To run PalettePal
Once all libraries are installed, clone the repository and run the main.py file in your terminal
